Privacy Policy for Anonymous's Utilities

Last updated: 2026. 07. 25.

Anonymous's Utilities is a Discord bot that provides moderation, verification, ticket, backup, and server management features.

Information We Collect

To provide its features, Anonymous's Utilities may process and store:

  • Discord user IDs
  • Discord server IDs
  • Discord role IDs
  • Discord channel IDs
  • Server configuration settings
  • Bot permission settings
  • Ticket system settings
  • Verification settings
  • Automod settings
  • YouTube notification settings

Some features may temporarily process message content, such as the automod system, to detect blocked words and perform moderation actions.

How We Use Information

The collected information is only used to provide and maintain bot features, including:

  • Moderation tools
  • Server configuration
  • Verification systems
  • Ticket management
  • Automated notifications
  • Security features

We do not sell, share, or use collected information for advertising purposes.

Data Storage

Configuration data is stored by the bot owner on the system where the bot is hosted.

The bot only stores information required for its features. Temporary data, such as verification CAPTCHA information, is automatically removed when it expires or is no longer needed.

Third Party Services

Anonymous's Utilities uses Discord services and may interact with YouTube public feeds for upload notifications.

Data handled by Discord or other third-party services is subject to their own privacy policies.

Data Removal

Server owners or users can request deletion of stored data related to the bot by contacting the bot owner.

Some information may need to be removed manually because the bot does not provide a public data deletion command.
